# Security policy

Trove handles API traffic in memory and is designed never to store or log credentials. What it stores and
where is listed in [PRIVACY.md](PRIVACY.md); the attackers it considers, and the ones it does not, are in
[docs/threat-model.md](docs/threat-model.md); the latest review's findings, including open ones, are in
[docs/security-findings.md](docs/security-findings.md).

## Reporting a vulnerability
Please report privately through GitHub's "Report a vulnerability" feature on this repository (Security tab). Do not file public issues for security problems. Include steps to reproduce and never include real API keys.

A fuller policy (supported versions, response times) will be added before the first release.
