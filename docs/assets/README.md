# Assets

- `Trove-logo.svg`: the Trove logo.
- `trove-banner.svg`: the README banner. It inlines the logo's vector paths, and the wordmark and tagline are drawn as outlines, so it renders the same everywhere with no font installed.

The banner text uses two typefaces under the [SIL Open Font License 1.1](https://openfontlicense.org): **Sora** for the wordmark (copyright 2019 The Sora Project Authors) and **Bricolage Grotesque** for the tagline (copyright 2022 The Bricolage Grotesque Project Authors). Only outlines of the letters are used; no font files are included in this repository.
