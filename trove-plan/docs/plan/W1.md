# W1. Make A/B verdicts reachable (v0.5–v0.6)

Today the A/B needs at least 20 sessions per arm. The smallest change it can reliably detect is about 2.8 × CV × √(2/n), so at that size it only sees very large effects (measurement.md):

## 1.1 [M]
Change: Make cost per turn and cost per new (uncached) input token the primary metrics. Keep session cost as a secondary metric
Where: `internal/measure`, `internal/experiment`
Done when: The report shows all three, each with a seeded bootstrap range

## 1.2 [M]

Where: `internal/measure`, `docs/benchmark-methodology.md`
Done when: Replaying stored sessions gives a narrower range for the same data

## 1.3 [M]

Where: `internal/measure`, `internal/cli/gateway.go`, `hooks.Maintain`
