# W5. Input-side coverage, T1 (v0.7–v0.8)

78% of tool-output tokens go through Claude Code's built-in Read, Grep and Glob tools, which shell hooks never see. That is why this workstream reaches beyond Bash.

## 5.1 [M]
Change: Collapse duplicate results in hooks, using an output hash on PostToolUse for Bash, Grep and Glob, and for Read once probed. There is no time-based expiry, unlike ZTK's time-limited cache
Where: Hooks (`post_tool_output`)
Done when: The existing re-fetch guardrail (`hook_fetch_back`) covers it (PR #5)

## 5.2 [M]
Change: For very large Read results, return an outline first through `updatedToolOutput`, reusing the MCP outliner. The full content stays fetchable
Where: Hooks, MCP outliner
Done when: Ships only after the live probe confirms the Read output shape, with a guardrail on extra reads

## 5.3 [M]
Change: Extend the output trimmer to JSON and logs: keep errors, outliers and the first and last entries. Incident logs save only 2.5% today
Where: `output_trimmer`
Done when: The checker confirms every error line is kept and the full output is stored byte for byte

## 5.4 [M]
Change: Offer scripts the agent keeps retyping as `trove_run` commands through `trove fix`, detected by hashed command. Caveman found one machine rewrote the same script 394 times in a week
Where: Fixer, MCP
Done when: Adoption is measured by the existing `adopted` counter

## 5.5 [S]
Change: Install the MCP tool-preference snippet (`trove mcp snippet`, about 70 tokens) with consent, as T2. Without it, agents tend to stick to their built-in tools
Where: Plugin, Fixer
Done when: Adoption and overhead are both measured

## 5.6 [L]
Change: Add Cursor and Gemini CLI adapters, starting with history parsing and repeat-read prevention. Both have the pre-tool hooks that ZTK already uses
Where: New adapters, `internal/hookcaps`
Done when: A per-agent live probe is recorded before any rewrite is enabled

## 5.7 [M]
Change: Finish Codex: add output rewriting, and promote the cargo and pytest quiet rules from shadow once error visibility is verified (PR #5)
Where: `internal/logs/cxhistory`, probe
Done when: A Codex live probe passes
